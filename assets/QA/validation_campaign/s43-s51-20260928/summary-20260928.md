## Scenarios and commands

### S43-KILLPROCESS-TREE

The PowerShell harness started a hidden disposable `pwsh.exe` root and child
whose command lines contained the repository path and the supported backend
marker `server.app:app`. It verified the selected root and child through
`Win32_Process`, ran:

```powershell
.\start_on_windows.ps1 -Action KillProcesses
```

The launcher reported `Stopping 4 XREPORT process(es)` and
`All XREPORT application processes and configured listeners were stopped`.
The harness then verified `REMAINING=` and no 5003/8003 listeners. The extra
tree entry was the Windows console host associated with the disposable child;
the launcher used the root `/T /F` termination path and no interception stub.
