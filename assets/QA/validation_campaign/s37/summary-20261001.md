## Implemented gated-provider enforcement

The gate was previously `BLOCKED` because a gated, not-installed public model
passed the generate admission check and started a background job that could
only fail at load time. The contract is now enforced before job start:

- Backend (`app/server/services/inference.py`): `generate_reports` now rejects
  any public gated model whose status is not `ready` with HTTP 409
  `"Gated model requires authorized access and a local installation before
  inference: <ref>"`. A locally installed and validated gated model remains
  allowed. Covered by
  `app/tests/unit/test_inference_service.py` (reject-not-installed,
  allow-ready, plus the existing degraded-model rejection).
- Client (`app/client/src/app/pages/inference.page.ts`): `canGenerate` now
  excludes a public gated model that is not `ready`, the Generate button label
  renders `Access required` instead of `Download and generate`, and the model
  notice already surfaced `Access is required before this model can be
  downloaded.` with an `Open model access page` link. Covered by
  `app/client/src/app/pages/job-cancellation.pages.spec.ts`.
